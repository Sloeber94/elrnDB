# Fuses and relays (Alfa 159)

This note describes the Alfa 159. Other models have their own junction units; their fuse and relay
index (`ai/lookup/fuses.html` in each model's text version) is generated the same way.

## Where they are in the manual

All junction units, fuses and relays, with their ratings, are listed in
**Descriptions › 55 Electrical equipment › 5505 Instrument/gauge electrical circuits** (`#/939003529`).

| Unit | Location | Wiring code | Rated in the tables |
|---|---|---|---|
| CBA | on the battery | B099 | 4 first-level power fuses (F70–F73) |
| CFO | optional fuses, next to the CBA | B098 | heater fuses (JTD only) |
| CVM | engine compartment | B001 | 23 fuses, 12 relays (T02–T20) |
| CPL | dashboard (under-dashboard junction unit, "B2" in the text) | B002 | 25 fuses, e.g. F-35 7.5 A mini |
| CVB | luggage compartment | B045 | 20 fuses, 5 relays (T21–T25) |

The same fuse number can exist in more than one unit, so always state the unit. The lookup lists the
unit for every rating.

## Reading the codes

- The manual writes fuses as **F-35** in the tables and **F35** in the text. Both are the same fuse.
- **Fuse codes (F1 to F99) are not component codes (F001 to F099, which are lamps and motors).** Fuse
  F35 is not lamp F035.
- Relays are T + number (T02, T21).
- Text gives fuse locations such as "second from the right in the top row" of the junction unit.

## Lookup

The AI text version has the full lookup: https://sloeber94.github.io/elrnDB/alfa/159/en/ai/lookup/fuses.html
(`docs/alfa/159/en/ai/lookup/fuses.html`). It contains:
- the ratings table for each junction unit: 72 fuses and 17 relays
- for every fuse or relay, its rating and every sentence of the manual that names it

It is generated by `fuse_ratings()` in `pipeline/aisite.py`. That function reads any table in the manual
that has a CODE column and an amperage column, and takes the table's junction unit from the nearest
heading above it that names a unit.
