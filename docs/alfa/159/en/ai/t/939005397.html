Applies to: engines: 1.8, 1.9 JTS, 2.2 JTS, 3.2 JTS; all production periods

1

TRANSPONDER CHECK

All OK

Problems encountered

Operation

Check for the presence of the Transponder inside the TEG reader and check its condition

Move on to Step 2

TEG transponder defective/unsuitable

Restore TEG and, if necessary, programme inside the Body Computer

2

KEY PROGRAMMING CHECK

All OK

Problems encountered

Operation

Check whether the key used is part of the set programmed in the Body Computer

Move on to Step 3

Key not programmed

Reprogramme the key

3

CONTINUITY CHECK

All OK

Problems encountered

Operation

Check the continuity of the aerial contacts and the efficiency of the aerial

Move on to Step 4

Connections not correct

Restore the connections

See E7010 CODE

Aerial broken

Replace the aerial inside the TEG reader

Op. 5505A31 ELECTRONIC KEY ACKNOWLEDGEMENT DEVICE - R. R.

4

CONTROL UNIT COUPLING CHECK

All OK

Problems encountered

Operation

Check that the injection control unit and the Body Computer coupling is correct

Move on to Step 5

Body Computer not programmed

Programme the Body Computer

Engine control unit from a different vehicle to the one for the programmed control unit

Restore correct control unit matching

5

SERIAL LINE CHECK

All OK

Problems encountered

Operation

Check the continuity of the engine control unit and Body computer serial line as well as the insulation to earth

See E5030 PETROL ENGINES ELECTRONIC MANAGEMENT

Move on to Step 6

Connections not correct

Restore the correct connection.

Insulation not correct

Restore the correct insulation

6

CONTROL UNIT OPERATION CHECK

All OK

Problems encountered

Operation

Check the correct operation of the Body Computer/engine control unit

End of diagnosis

Body Computer defective

Replace Body Computer

Op. 5505A32 BODY COMPUTER - R.R

Engine control unit defective

Replace the engine control unit

Op. 1056F82 CONTROL UNIT SINGLE OF INJECTION IGNITION SYSTEM R R
