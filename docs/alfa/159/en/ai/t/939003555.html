PRELIMINARY CHECKS

All OK

Problems encountered

Operation

Check that:

. The doors lock mechanically using the insert that comes with the vehicle

. The key remote controls are both working and transmit the RF codes

. The time that the key remote control buttons is pressed is correct and that they have not been pressed too many times

Move on to Step 1

The doors do not lock using the insert

Proceed as instructed in the

See table P010 CENTRAL LOCKING NOT WORKING

One remote control is not working on account of a failure

Replace the remote control and programme the keys

Op. 5580E ANTI-THEFT DEVICE

Both remote controls are not working

There is a lack of synchronism with the variable code: restore the code synchronism by carrying out the

See Test 5580EA ANTI-THEFT REMOTE CONTROL OPERATION CHECK

The transmitter battery has been changed but it is not working

There is a lack of synchronism with the variable code: restore the code synchronism by carrying out the

See Test 5580EA ANTI-THEFT REMOTE CONTROL OPERATION CHECK

The remote controls do not work in certain places where there is strong electro-magnetic interference

It is not possible to carry out any type of operation. Carry out the test somewhere far away from anti-theft transmitters, hospitals, electric power stations, industrial zone, radio-television transmitters

The buttons in the remote control have been pressed for too long or the remote control button has been pressed too many times

The NBC system has gone into protective mode. Wait 30 seconds without pressing the buttons and try again

All OK

Operation

Logistic mode activated

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Check:

. There are no faults at the TEG-Reader node

. The presence of the alarm system at the CAN

. There are no control unit errors at the Body Computer

. The programming state of the remote controls

Move on to Step 3

Remote control battery run down

Check the voltage of the remote control battery by carrying out the

See Test 5580EA ANTI-THEFT REMOTE CONTROL OPERATION CHECK

and, if run down, replace it

Remote controls not working as they are not programmed

Carry out the remote control programming procedure

Op. 5580E ANTI-THEFT DEVICE

Remote controls used do not conform

Replace the remote controls checking their conformity and programme them

Op. 5580E ANTI-THEFT DEVICE
