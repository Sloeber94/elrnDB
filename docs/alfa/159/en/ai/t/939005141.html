The diagnostic equipment signals: Error P0168 (Limit for high fuel temperature)

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

This error is detected if there is a mechanical problem with the engine or if the system is overheating as a result of overloading The quantity of fuel injected is reduced as a result.

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the diagnostic equipment and select the Bosch EDC 16C39 electronic control unit, checking that none of the following errors are present:

P0180 - Fuel temperature sensor

P1612 - Fuel filter heating relay control

Move on to Step 2

1. Error P0180 present

1. Proceed as instructed in the

See Test 1060EA DIESEL FUEL TEMPERATURE CHECK

2. Error P1612 present

2. Proceed as instructed in the

See Test 5505AC CHECK DIESEL PREHEATING RELAY

2

ENGINE COOLING SYSTEM CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the fuel cooling system is working properly

Check the engine cooling system is working properly.

Check that there are no engine oil leaks and that the engine oil level is correct

Op. 0010T11 ENGINE OIL - CHECK LEVEL AND TOP UP, IF NECESSARY

If all these conditions are followed, the malfunction is caused by poor use of the engine

End of diagnosis

1. Malfunction of the fuel cooling system

1. Restore the correct operation of the system

2. Malfunction of the engine cooling system

2. Restore the correct operation of the system

3. Engine oil leaks

3. Continue as instructed in the

See table X12 ENGINE OIL LEAKS

4. Engine oil level beyond permitted limits

4. Restore the correct engine oil level
