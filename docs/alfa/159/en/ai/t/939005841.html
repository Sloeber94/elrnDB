Removing

Refitting

The injection-ignition system control unit is a component that is sensitive to electrostatic interference. Do not touch the injection-ignition system control unit once the engine is started unless the static electricity has been discharged first by touching the bodyshell.

1. Disconnect the electrical connections for the injection/ignition system control unit.

Description

Connector

1

Engine management control unit

See M010 ENGINE MANAGEMENT ECU

2. Undo the bolt and release the earth lead from the control unit.

3. Undo the bolts (3a) and remove the injection/ignition system control unit (3b).

The rear bolt on the engine coolant reservoir side also secures the earth lead.

Applies to: engines: 1.8; all production periods
