7040L37 GEAR LEVER TRIM - R.R

Applies to: all engines; all production periods

Removing

Refitting

1. Release the boot retaining button.

2. Lift up the trim (2a) slightly releasing the internal retainers (2b).

3. Disconnect the electrical connection.

Description

Component

HAZARD WARNING LIGHTS SWITCH

See H020 HAZARD WARNING LIGHTS SWITCH

4. Disconnect the electrical connection.

Description

Component

SWITCH UNIT ON TUNNEL

See H035 TUNNEL SWITCHES

5. Keep the trim.

Applies to: all engines; all production periods

- If necessary:

Op. 7040A62 SWITCH UNIT ON TUNNEL R R

Applies to: all engines; all production periods

Refitting

Removing

- Check that the trim is not damaged.

- If removed, position the switch unit.

Op. 7040A62 SWITCH UNIT ON TUNNEL R R

- Connect the electrical connections.

- Position the trim and attach the retainers.

- Fit the boot retaining button.
