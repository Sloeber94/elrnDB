Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

FUNCTIONAL DESCRIPTION

The Cruise Control function is managed by engine management control unit M10 upon a request by Cruise Control system control H7 located to the left of the steering wheel.

The control H7 receives an ignition-controlled power supply (INT) pin 2 from the line protected by fuse F35 of the junction unit under the dashboard B2 .

The control H7 is connected to control unit M10:

- at pin 77 of connector A, with the ON/OFF signal

- at pin 38 of connector A, with the RESUME signal

- at pin 56 of connector A, with the SET + signal

- at pin 78 of connector A, with the SET - signal

The control unit M10 also uses the "pedal released" signals (N.C. contact) coming from the second brake lights switch contact I30 and the signal coming from the clutch switch I31 to manage the Cruise Control function.

See E5050 DIESEL ENGINES ELECTRONIC MANAGEMENT

Engine management control unit M10 connects via the CAN line to the Body Computer and instrument panel E50 to manage the Cruise Control on warning light.
