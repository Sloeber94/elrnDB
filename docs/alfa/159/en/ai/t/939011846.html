Applies to: all engines; all production periods

DESCRIPTION

This vehicle is equipped with a starting system known as Smart-Key where there is no longer a traditional ignition key having been replaced with an electronic key "T.E.G." (Transmitter for Entry and go) combined with an electronic key reader and TEG-Reader radio frequency receiver.

Access to the vheicle through radiofrequency recognition of the remote control incorporated in the TEG is entirely the same as what takes place with the traditional remote control incorporated in the key fob.

The vehicle is not switched on/started up by inserting the key in the ignition switch (which is no longer present) and turning it but by inserting the TEG in the TEG Reader and activating the START/STOP button.

See E5010 STARTING AND RECHARING

The distribution of the power supply to the vehicle (ignition-controlled INT, INT/A, AVV, etc.) is managed by the steering lock node and takes place in entirely the same way as for models equipped with a traditional key.

See E1010 POWER SUPPLY

As there is no longer a mechanical key, the steering lock function is produced electrically via the steering lock electronic control unit, connected to the CAN. The release of the steering by the steering lock node takes place when the ignition-controlled INT is activated.

The steering is locked by the steering lock node when the TEG is extracted from the TEG Reader.

For more details

See descriptions 5520 ENGINE STARTING
