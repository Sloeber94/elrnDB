Applies to: all engines; all production periods

With the telephone activated, the voice of the other speaker is heard, but they cannot hear the speaker in the vehicle.

This table does not consider faults due to service provider or phone function malfunction

Applies to: all engines; all production periods

The following telephones are enabled to operate with the Bluetooth system and are supported by the system on the vehicle:- Audiovox®: SMT 5600 (Orange™ C500)*- Motorola®: V525*, V600*, Mpx220**- Nokia®: 6230, 6600†, 6820, 7610*- Sony Ericsson®: k700i, T610**, T637**, Z600*** The system is not currently able to support a GPRS connection (General Packet Radio Services) when it is connected to this mobile phone.** The system is not currently able to support a hands-free system when it is connected to this mobile phone.† The system is not currently able to support call waiting when it is connected to this mobile phone.

Applies to: all engines; all production periods

Test results

1

ELECTRICAL CIRCUIT CHECK

All OK

Problems encountered

Operation

Check the continuity and the insulation of the electrical circuit between the microphone and the Bluetooth control unit

See E3570 INTEGRATED RADIO PHONE

Move on to Step 2

Electrical connections faulty

Restore the correct connections

2

MICROPHONE NO LOAD VOLTAGE CHECK

All OK

Problems encountered

Operation

Check the no load voltage value at the microphone

End of diagnosis

1. No load voltage between 3 and 8 V

2. Voltage outside of the previous range

1. Replace the microphone

2. Replace the Bluetooth® control unit

Op. 5570T49 BLUETOOTH ELECTRONIC CONTROL UNIT - R.R.
