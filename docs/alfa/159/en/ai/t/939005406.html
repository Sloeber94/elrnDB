The following telephones are enabled to operate with the Bluetooth system and are supported by the system on the vehicle:- Audiovox®: SMT 5600 (Orange™ C500)*- Motorola®: V525*, V600*, Mpx220**- Nokia®: 6230, 6600†, 6820, 7610*- Sony Ericsson®: k700i, T610**, T637**, Z600*** The system is not currently able to support a GPRS connection (General Packet Radio Services) when it is connected to this mobile phone.** The system is not currently able to support a hands-free system when it is connected to this mobile phone.† The system is not currently able to support call waiting when it is connected to this mobile phone.

PRELIMINARY CHECK

All OK

Problems encountered

Operation

Check that when the various controls on the steering wheel are pressed they all work properly as indicated in the Owner's Handbook and that error messages do not appear in the instrument panel

End of diagnosis

2. The voice recognition and/or main buttons are not working properly

3. The ESC, +, -, SRC and/or Search buttons are not working properly

BUTTON STATUS CHECK

All OK

Problems encountered

Operation

Using the diagnostic equipment, display the following parameters and check whether the values displayed switch when the buttons are pressed/released:

- Up button

- Telephone button

- Down button

- Source button

- Mute button

- Voice button

Move on to Step 4

One or more of the buttons do not switch when pressed/released

Move on to Step 3
