Electric seat position memorizing not working/not working properly

Applies to: all engines; all production periods

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check whether the seat position has been memorized with the vehicle stationary or with the speed above 10 Km/h.

Move on to Step 1

The memorizing has taken place with the vehicle speed above 10 Km/h.

Carry out the memorizing of the seat positions with the vehicle stationary or with the speed below 10 Km/h.

1

CHECK ON SEAT CONTROL UNIT CONNECTIONS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the connector is correctly fitted in the seat control unit and also check for oxidation at the connector/control unit contacts.

Move on to Step 2

1. Connector partly fitted

1. Fit the connector correctly in the control unit.

2. Presence of oxidation at the connector/control unit contacts.

2. Clean the control unit/connector contacts using special products.

2

CHECK ON SEAT CONTROL UNIT WIRING

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the condition of the wiring at the seat control unit see wiring diagram

See E3076 ELECTRICALLY-ADJUSTABLE SEATS

Move on to Step 3

Tears in the control unit connection wiring or wires possibly detached from the wiring connector.

Replace the torn/broken wiring.

3

CHECK ON SEAT CONTROL UNIT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the condition of the seat position memory control unit

End of diagnosis

Breaks or openings in the seat control unit casing.

Replacement of seat position memory control unit

Op. 7045J50
