Applies to: all engines; all production periods

With the key ON, the Body Computer does not display any operating errors in one more of the different types of lights:

Applies to: all engines; all production periods

  • side lights
  • brake lights
  • rear fog lamps
  • direction indicators
  • no. plate lights

Applies to: all engines; all production periods

These lights are not operational, but the Body Computer does not turn on the relevant light failure warning light

Applies to: all engines; all production periods
