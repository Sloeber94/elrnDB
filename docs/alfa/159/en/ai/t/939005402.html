Using the function for the mobile phone in question, switching from individual mode to hands-free mode does not take place.

This table does not consider faults due to service provider or phone function malfunction

Applies to: engines: 1.8, 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

The following telephones are enabled to operate in hands-free/individual mode with the Bluetooth system and are supported by the system on the vehicle:- Audiovox®: SMT 5600 (Orange™ C500)*- Motorola®: V525*, V600*- Nokia®: 6230, 6600†, 6820, 7610*- Sony Ericsson®: k700i* The system is not currently able to support a GPRS connection (General Packet Radio Services) when it is connected to this mobile phone.† The system is not currently able to support call waiting when it is connected to this mobile phone.
