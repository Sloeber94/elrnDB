Applies to: all engines; all production periods

The Cruise Control system controls do not work under any circumstances

Applies to: all engines; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the diagnostic test equipment (Examiner or other instruments) to the tester input.

Check for the presence of faults in the engine management control unit

Move on to Step 2

1. Error detected in the control unit

1. Continue following the instructions for the diagnostic equipment

2. No communication with the control unit

2. Restore the connection between the engine management control unit and the diagnostic connector: wiring diagram

See E5060 CRUISE CONTROL

2

CRUISE CONTROL SELECTOR CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the Cruise Control contacts are working properly

See Test 5580AA Cruise Control ON/OFF control check

Move on to Step 3

No continuity

Replace the Cruise Control lever assembly

See Test 5580A10 CRUISE CONTROL LEVER ASSEMBLY - R+R

3

SUPPLY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the ignition key in the ON position and the Cruise Control ON, check that there is a voltage signal from the Cruise Control to the engine management control unit:

See E5060 CRUISE CONTROL

Move on to Step 4

1.No voltage detected

1.Repair the connections:

See E5060 CRUISE CONTROL

2.Fuse broken

2.Replace the fuse after having eliminated the cause

4

CONNECTIONS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the electrical continuity of the wiring between the junction unit, ignition switch, engine management control unit and Cruise Control system control:

See E5060 CRUISE CONTROL

Move on to Step 5

No continuity

Repair the connections:

See E5060 CRUISE CONTROL

5

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

End of diagnosis

The fault persists: control unit defective

Replace the engine management control unit

Op. 1056B82 INJECTION/IGNITION SYSTEM E.C.U. (ONE) - R + R
