Op. 5560B10 CONTROL PANEL - R+R

1. Unscrew collar bolts (1a), then lower steering column (1b).

2. Use a drill to remove rivets (2a) securing the flexible trim (2b) to the dashboard trim.

Use a vacuum cleaner to recover material removed using the drill.

3. Recover the flexible trim.

Applies to: all engines; all production periods

Refitting

Removing

- Check that the flexible trim is not damaged.

- Position the flexible trim and apply rivets.

- Raise the steering column and tighten the collar bolts.
