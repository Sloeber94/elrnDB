Applies to: all engines; all production periods

When the lights are activated using the stalk, the relevant warning light does not light up on the instrument panel

Applies to: all engines; all production periods

N.B: The warning lights activated when the stalk is operated are:

Applies to: all engines; all production periods

  • Side lights/number plate lights
  • Main beam headlamps
  • Direction indicators

Applies to: all engines; all production periods

0

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the key ON, operate all the lights from the stalk, i.e.:

  • Using the wheel, side lights/number plate lights
  • With the stalk, high beams (both fixed and flashing positions)
  • With the stalk, turn signals (right and left) and check they are activated
