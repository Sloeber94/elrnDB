Removing

Refitting

The following procedure describes the removing-refitting of the left rear wheel rpm sensor, carry out the same operations for the right rear wheel rpm sensor.

- Position the vehicle on a lift.

- Make sure that the ignition key is in the OFF position, then disconnect the battery terminal (-).

Description

Connector

-

Battery

See A001 BATTERY

Op. 4450B06 LEFT REAR WHEEL - R.R

1. Partly release the wheel arch and disconnect the electrical connection for the left rear wheel rpm sensor.

Description

Connector

1

Left rear wheel sensor for ABS

See K075 LEFT REAR WHEEL SENSOR FOR ABS

Applies to: all engines; all production periods

1. Release the electrical wiring for the left rear wheel rpm sensor from the intermediate fastenings.

2. Undo the bolt (2a) and remove the left rear wheel rpm sensor (2b).

Applies to: all engines; all production periods

Refitting

Removing

1. Position the left rear wheel rpm sensor (1a) in its housing and secure it tightening the bolt (1b) to the recommended torque.

2. Secure the electrical wiring for the left rear wheel rpm sensor to the intermediate fastenings.

Applies to: all engines; all production periods

- Connect the electrical connection for the left rear wheel rpm sensor and place the wheel arch back in its housing.

Op. 4450B06 LEFT REAR WHEEL - R.R

- Connect the negative battery terminal.

- Remove the vehicle from the lift.
