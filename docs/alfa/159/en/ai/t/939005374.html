5070TP BLUETOOTH SOFTWARE LANGUAGE UPDATE PROCEDURE

Applies to: all engines; all production periods

If a customer comes to the repair workshop with a vehicle on which a Bluetooth® system is installed and an Update CD is available in the workshop, it is highly advisable to run this procedure at the end of the repairs.

CHECK TO BE PERFORMED

RESOLUTION IF THE CHECK IS NOT OK

1

Disconnect the mobile phone enabled by the Bluetooth® system and remove from inside the vehicle.

If the mobile phone is not removed from the vehicle and a call is received during the installation process, the procedure will not be successful

2

Insert the USB pen in the USB port of the diagnostic instrument.

Insert the update CD in the diagnostic equipment, then switch it on. Select the language for the instructions.

When the final user licence appears, press I Accept.

You cannot continue if you do not press I Accept

3

Select Create update pen in the main menu, wait for the software to install (Capacity update USB error should not appear on the panel) on the USB pen and remove.

The USB pen is not supported by the diagnosic instrument or sofware (or, in the event of an error, its capacity is insufficient): use a compatible USB pen of sufficient capacity.

Pens supported are with standard USB 1.0, 1.1 or 2.0 connectors and capacity up to 1 GB. The following models are certainly supported: Lexar™ JumpDrive® 2.0 512 MB, Memorex® Travel Driver 256 MB USB 2.0, Memorex® Travel Driver 1 GB USB 2.0, PNY® Attaché 256 MB USB 2.0, SanDisk® Cruzer™ micro 256 MB USB 2.0, SanDisk® Cruzer™ Mini 256 MB / 1 GB USB 2.0 and Sony® Micro Vault®

4

Press the START/STOP button (panel off).

Remove the radio

Op. 5570T80 CAR RADIO EQUIPMENT - R+R

Insert the USB pen in the special opening in the Bluetooth® device (behind the radio).

Press the START/STOP button (panel on).

Check that the words "Update complete" appear on the instrument panel at the end of the update and not one of the "USB key error" or "USB update Capacity/Firm/File error" errors.

The procedure will not be successful if the USB pen is removed during the installation procedure. Re-insert the pen, wait for 30 seconds and repeat this step

If an error is present, try to repeat this Step.

If the problem persists, move on to Step 6

5

Press the START/STOP button (panel off).

Remove the USB pen from the USB port. The test is over

6

The problem may be caused by a non-original update CD.

Ensure that a copy of the update CD has not been used to run the procedure

Replace the Bluetooth® control unit

Op. 5570T49 BLUETOOTH ELECTRONIC CONTROL UNIT - R.R.
