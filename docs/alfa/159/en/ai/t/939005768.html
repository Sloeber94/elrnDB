Removing

Refitting

1. Disconnect the electrical connection for the accelerator pedal with built in potentiometer.

Description

Connector

1

Accelerator pedal potentiometer

See K055 ACCELERATOR PEDAL POTENTIOMETER

2. Undo the bolts (2a) and remove the accelerator pedal with built in potentiometer (2b).

Applies to: all engines; all production periods

Refitting

Removing

- Place the accelerator pedal with built in potentiometer back in its housing and secure it to the support using the bolts.

- Connect the electrical connection for the accelerator pedal with built in potentiometer.
