Removing

Refitting

- Position the vehicle on a lift.

- Draw off the power assisted steering fluid from the reservoir using a suitable syringe.

1. Disconnect the fast-on connector of the return line from the power steeering box to the intermediate pipe, intermediate pipe side.

Applies to: engines: 1.9 JTS, 2.2 JTS; all production periods

1. Undo the connector (1a) and disconnect the return pipe from the power steering box to the intermediate pipe(1b), power assisted steering box side.

2. Remove the return pipe from the power steering box to the intermediate pipe.

Applies to: engines: 1.9 JTS, 2.2 JTS; all production periods

Refitting

Removing

1. Refit the return pipe from the power steering box to the intermediate pipe.

2. Connect the return pipe from the power assisted steering box to the intermediate pipe (2a), power assisted steering box side and tighten the connector (2b) to the recommended torque.
