7040L40 FRONT DOOR RUNNING BOARD (ONE), LEFT OR RIGHT - R.R.

Applies to: all engines; all production periods

Removing

Refitting

- Open the front door.

1. Release the door housing seal in the area of the running board.

2. Remove the running board (2a), lifting it up at the back to release the retainers (2b), then pushing it forwards to release the retainers (2c) and lastly moving it backwards to release the front retainer (2d).

Applies to: all engines; all production periods

Refitting

Removing

- Check that the running board is not damaged.

- Place the running board in position and attach the retainers.

- Fit the door housing seal.
