Applies to: all engines; all production periods

When the lights/heated rear windscreen are deactivated from the control panel, the warning light in the instrument panel does not go out

Applies to: all engines; all production periods

N.B: The following warning lights are on through control panel activation:

Applies to: all engines; all production periods

  • Fog lights (left control panel)
  • Rear fog lamps (left control panel)
  • Hazard warning lights (control panel on centre tunnel)
  • Heated rear windscreen (climate control system control panel)

Applies to: all engines; all production periods

ALL OK

ACTION

With the ignition OFF, activate the hazard warning lights and switch them off and check that they come on/go out.

With the ignition ON, activate all the functions in question using the left control panel and switch them off, namely:

  • fog lights
  • rear fog lamps
  • heated rear windscreen and check that they are activated/deactivated
