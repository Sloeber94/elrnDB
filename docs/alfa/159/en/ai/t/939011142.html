Removing

Refitting

Description

Component

1

PASSENGER SIDE FRONT ELECTRIC WINDOW MOTOR

2. Undo the bolts.

3. Remove the electric window motor releasing the splined shaft.

Applies to: all engines; all production periods

Refitting

Removing

- Check that the electric window motor is not damaged.

The bushes in which the window motor bolts are engaged must be replaced.

1. Replace the bushes.

2. Position the window motor.

3. Tighten the fixing bolts.

4. Connect the electrical connection.
