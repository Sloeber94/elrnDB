The diagnostic equipment signals: Error P2226 (atmospheric pressure sensor), with detail "beyond the upper limit"

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

This error is detected if the control unit detects an invalid signal from the barometric pressure sensor. As a result, the control unit carries out the calculations with a replacement value of 0.751 bar, the control of the preheating time is affected and the exhaust gas recirculation valve is switched off.

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods
