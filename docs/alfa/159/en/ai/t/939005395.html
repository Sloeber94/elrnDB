Applies to: all engines; all production periods

NOTE: one headlamp comes on normally but the vertical adjustment is not carried out

Applies to: all engines; all production periods

NOTE: if the control unit for the master headlamp is being replaced, delete the errors in the memory using the Examiner and calibrate the system

Applies to: all engines; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that there are no errors by connecting to the master headlamp (left side) control unit.

Check that there are no errors by connecting to the slave headlamp (right) control unit.

End of diagnosis

Presence of error detected

B1040 - Headlamp alignment corrector

Move on to Step 2

2

CHECK ON CONNECTION INSIDE THE HEADLAMP

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the connection for the headlamp vertical adjustment motor is correctly connected by carrying out the test

See Test 5540BM CHECK THE HEADLAMP ALIGNMENT MOTOR SUPPLY WIRING

Move on to Step 3

3

MOTOR OPERATION CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Replace the left headlamp

Op. 5540B81 LEFT GAS DISCHARGE LIGHT CLUSTER - R.R.

or right headlamp

Op. 5540B82 RIGHT GAS DISCHARGE LIGHT CLUSTER - R.R.

(the broken one) and check that the motor is working properly

End of diagnosis

1. Right headlamp alignment corrector not working

1. Move on to Step 4

2. Left headlamp alignment corrector not working

2. Move on to Step 4

4

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Refit the headlamp replaced previously and replace the ballast control unit for the headlamp that is faulty

Op. 5540B42

End of diagnosis

The fault persists

Contact technical service for further information on the problem
