The diagnostic equipment signals: Error P1612 (fuel filter heater relay control), with detail "excessive temperature"

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

This error is detected if the temperature of the electronic control module detected is not within the planned limits for at least 0.3 secs.

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

Fuel heating relay check

ALL OK

PROBLEMS ENCOUNTERED

ACTION
