Applies to: all engines; all production periods

When the lights/heated rearscreen are activated using the stalk, the relevant warning light does not light up on the instrument panel

Applies to: all engines; all production periods

N.B: The warning lights activated from the panel are:

Applies to: all engines; all production periods

  • Foglamps (left control panel)
  • Rear foglamps (left control panel)
  • Hazard lights (on the central tunnel)
  • Heated rearscreen (climate control panel)

Applies to: all engines; all production periods

0

ALL OK

ACTION

With the key OFF, operate the hazard lights and check they come on.

With the key ON, turn all the functions in question on from the left control panel, i.e.:

  • fog lights
  • rear fog lamps
  • heated rearscreen and check they come on
