Applies to: all engines; all production periods; only with equipment: Bluetooth

DESCRIPTION

The handsfree system for Bluetooth phones - built into the dashboard - allows mobile phones to be used on board whilst assuring customer safety and function.

- Bluetooth receiver;

- integral Voice Recognition unit including microphone (located next to the front courtesy light);

- integral Text to Speech unit.

- USB interface for Media Player.

The control unit is also connected to radio controls on the steering wheel (two special keys for this function are provided in addition to the radio control keys).

The alphanumeric display used is that of the control panel.
