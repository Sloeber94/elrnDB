Applies to: all engines; all production periods

When the selector which controls the headlamp alignment is operated (with the dipped headlamps on) the information on the display does not change. If the headlamp alignment is not workingSee table I080 HEADLAMP ALIGNMENT CORRECTOR NOT WORKING

Applies to: all engines; all production periods

1

HEADLAMP ALIGNMENT ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check:

  • connection between left control panel and NQS;
  • left control panel earth
  • connection between dashboard control unit and instrument panel

See E3080 HEADLAMP AGLINMENT CORRECTOR

Move on to Step 2

1. Connections not correct

1. Repair the connections

See E3080 HEADLAMP AGLINMENT CORRECTOR

2. Earths defective

2. Repair the earth contacts

See E3080 HEADLAMP AGLINMENT CORRECTOR

2

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the diagnostic equipment (Examiner Plus or Smart) to the diagnostic socket and check in active diagnosis at the instrument panel that all the display segments are working properly

Move on to Step 3

One or more segments not working

Replace the instrument panel

Op. 5560B10 CONTROL PANEL - R+R

3

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

End of diagnosis
