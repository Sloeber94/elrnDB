Refitting

- Position the vehicle on a lift.

Op. 1016A10 SOUND-PROOFING COVER - R.R

- Disconnect the electrical connections from the injectors.

Op. 1060F36 PIPES (ALL) FROM FUEL MANIFOLD TO INJECTOR - R.R.

1. Undo the injector bracket retaining nuts.

2. Remove the injectors (2a) complete with brackets using the tools (2b).

If a new injector/new inectors are fitted:- determine the identification code stamped on the top surface;- check, using an Examiner, the the new injector(s) is (are) recognized by the engine management control unit.

Start the removal beginning with the injector for cylinder no. 1 and continue with the injectors for cylinders 2, 3 and 4.
