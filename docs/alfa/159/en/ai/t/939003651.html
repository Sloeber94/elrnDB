Applies to: all engines; all production periods

N.B.: The brake node sends the ABS warning light on message via the C-CAN to the Body Computer which makes it available via the gateway to the Instrument Panel Node through the B-CAN.

Applies to: all engines; all production periods

If there are problems in the C-CAN, the control unit warning lights for this network will light up. The "CAN INFORMATION" check is designed for this eventuality

Applies to: all engines; all production periods
