Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

With the alarm on, the boot lid unlocking command is not enabled by the remote control.

Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

The boot lid locking/unlocking command is managed by the body computer node which sends the signal to the electrical lock.

Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

PRELIMINARY CHECK

All OK

Problems encountered

Operation

Make sure that the central locking system is working properly. In particular, check that the "independent boot" option is disabled.

Then close the doors using the remote control or the mechanical key.

Carry out the operations described above using the second remote control.

Move on to Step 1

Central locking not working: the doors and the boot lid are not closed/opened simultaneously.

Continue with the diagnosis of the central locking system

See table P010 CENTRAL LOCKING NOT WORKING

The fault persists, using the second remote control as well.

Move on to Step 3

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Connect the diagnostic equipment to the Body Computer Node and check that there are no errors.

Move on to Step 2

Errors detected: Boot lid opening relay feed short circuited.

Replace the boot lid relay feed.

Problems encountered

Operation

Keeping the Examiner diagnostic equipment connected, check, in the parameters ambient, that the boot lid opening/closing command using the remote control is correctly received.

The boot lid opening/closing command using the remote control is not received.

Move on to Step 3

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

In the parameters ambient, check that the remote control(s) is(are) working properly, in particular that each individual button is correctly received.

Move on to Step 5

The individual remote control(s) commands are not received correctly.

Replace the broken remote control(s).
