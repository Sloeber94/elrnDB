Applies to: all engines; all production periods

When the brake pedal is pressed, there is flexibility as far as the end of travel position with a consequent reduction in the braking action

Applies to: all engines; all production periods

1

CHECK FOR PRESENCE OF AIR

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check for the presence of air in the system

Move on to Step 2

Presence of air in the system

Bleed the air from the system

Op. 0010T65 HYDRAULIC BRAKE SYSTEM - BLEED AIR

2

BRAKE SERVO CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the brake servo is working properly

See Test 3330DA CHECK VACUUM PUMP OPERATION AND BRAKE SERVO VACUUM CIRCUIT

Move on to Step 3

Brake servo not working properly

Replace the brake servo assembly

Op. 3330D10

3

FLEXIBLE PIPES CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the condition of the flexible pipes.

End of diagnosis

Flexible pipes swollen or deteriorated.

Replace the flexible pipes involved

Op. 3330E HYDRAULIC BRAKE SYSTEM PIPES
