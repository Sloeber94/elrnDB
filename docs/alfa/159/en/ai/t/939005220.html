The diagnostic equipment signals: Error P0101 (flow meter signal), with detail "beyond the upper limit"

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

This error is detected if there is interference with the signal for the sensor at Pin 42 of the electronic control module.
