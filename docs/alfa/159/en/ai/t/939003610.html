When the key is inserted in the key recognition device the steering is not released.

Applies to: all engines; all production periods

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems encountered

Operation

First, check that:

- The battery is run down (not below 8.5 Volt)

- The key is recognized and that the Body asks for the release of the steering

Move on to Step 1

Battery run down

Recharge the battery

Key not recognized/the Body does not ask for the release of the steering

Replace the key with one that is recognized

1

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Connect the diagnostic equipment to the diagnostic socket and check:

- for the presence of possible errors at the Teg Reader node

- for the presence of possible errors at the steering lock node

- for the presence of possible errors at the B-Can

Move on to Step 2

Teg Reader power supply not correct

Restore correct power supply

See E7065 ELECTRIC STEERING LOCK

Presence of errors at the Teg-Reader

Continue as described by the diagnostic equipment

Presence of errors at the B-Can

Continue as described by the diagnostic equipment

2

ELECTRICAL CHECKS

All OK

Problems encountered

Operation

Using the diagnostic equipment as a multimeter, check:

- that the key recognition device is working properly

See Test 5505AF CHECK OF THE EFFICIENCY OF KEY ACKNOWLEDGEMENT DEVICE

- that the steering lock is working correctly

See Test 5580ED ELECTRIC STEERING LOCK CHECK

Move on to Step 3

3

STEERING LOCK OPERATION CHECK

All OK

Problems encountered

Operation

Using the diagnostic equipment, check in active diagnosis that the steering lock is working properly

End of diagnosis

Steering lock defective

Replace the steering lock node
