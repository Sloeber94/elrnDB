Applies to: all engines; all production periods

With the key on the milometer does not display the outside temperature.

Applies to: all engines; all production periods

0

PRELIMINARY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check:

  • That the panel brightness adjustment has not been selected.
  • That the mode button has not been pressed
  • That dashes are not displayed in place of the temperature
  • That failure messages have not been displayed

Move on to Step 1

1. Display shows other information

1. Restore display conditions using the control panel

2. There are dashes instead of the temperature

2. Move on to Step 2

1

ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the connections for the outside temperature sensor in the Driver's Door Node are correct

Check that the outside temperature sensor is working properly

Move on to Step 2

1.Connections defective

1.Restore the correct connections, if necessary, replace the wiring

See E6020 AIR CONDITIONING

2. Temperature sensor defective

2.Replace temperature sensor

Op. 5010D12 OUTSIDE AIR TEMPERATURE SENSOR ON DOOR MIRROR - R+R FOLLOWING ELECTRICAL CIRCUIT CHECK

2

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment to the diagnostic socket.

Check:

  • for faults in the instrument panel
  • for faults in the driver's door node

Move on to Step 3

1.Instrument panel defective.

1.Replace instrument panel

Op. 5560B10 CONTROL PANEL - R+R

2.Door node defective.

2.Replace driver's door node

Op. 5505A42 CONTROL UNIT (DIGITAL NETWORK NODE) IN DRIVER'S DOOR - R.R.

3

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present.

End of diagnosis
