CHECK USING DIAGNOSTIC EQUIPMENT

PROBLEMS ENCOUNTERED

ACTION

Using the Examiner check, in the Instrument Panel Node ambient, that there are no errors.

Move on to Step 2

Errors present

Continue as described by the diagnostic equipment

2

ACTIVE DIAGNOSIS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the Examiner in the Instrument Panel Node ambient check that the rain sensor failure warning light is correctly activated in Active Diagnosis

Move on to Step 3

The warning light does not flash

Replace the Instrument Panel

Op. 5560B10 CONTROL PANEL - R+R

3

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Using the Examiner check, in the Body Computer ambient, that there are no errors.

Move on to Step 4

Errors present

Continue as described by the diagnostic equipment

4

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Using the Examiner in the Body Computer ambient in Active Diagnosis that the serial line between the rain sensor and the Body Computer is in good condition

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

Move on to Step 5

1.Serial line broken

1.Renew serial line continuity

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

2.Serial line short circuited

2.Renew serial line insulation

5

CORRECT POWER SUPPLY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the power supply for the rain sensor is correct

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

Move on to Step 6

1.Sensor not correctly connected to earth

1.Restore earth connection

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

2.Power supply interrupted

2.Restore correct power supply

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

6

RAIN SENSOR CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the rain sensor is working properly.

End of diagnosis

Rain sensor not working properly.

Replace the rain sensor
