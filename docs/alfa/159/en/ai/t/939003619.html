J022 DOOR MIRROR DEFROSTING NOT WORKING

Applies to: all engines; all production periods

With the ignition ON, when the button in the control panel for the climate control is pressed, the external rear view mirrors do not heat up properly

Applies to: all engines; all production periods

If the battery voltage is below 11.6 V, the heated rear windscreen and rear view mirrors are not supplied by the control unit.

Applies to: all engines; all production periods

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the heated rear windscreen heats up properly when the button in the climate control system control panel is pressed.

Move on to Step 1

The heated rear windscreen does not heat up properly.

Proceed as instructed in the,

See table J021 HEATED REAR WINDSCREEN NOT WORKING

1

REAR VIEW MIRRORS POWER SUPPLY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Connection to earth for rear view mirrors;
  • Power supply line for rear view mirrors

See E3030 HEATED REAR WINDSCREEN AND DOOR MIRROR DEFROSTING

Move on to Step 2

Connection broken.

Restore the correct connections.

2

MIRROR FILAMENTS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the condition of the filaments inside the mirror.

End of diagnosis

Filaments broken.

Restore the condition of the mirror filaments. If necessary, replace the mirror reflective element

Op. 7005R35 DOOR MIRROR REFLECTOR (ONE), LEFT OR RIGHT - R.R
