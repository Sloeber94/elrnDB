Applies to: all engines; all production periods; only with equipment: Connect Nav+

DESCRIPTION

In the specification with built in CONNECT NAV + radio-phone-navigation system, the phone (GSM module and SIM-CARD reader) is built into the system.

The system includes:

- GSM module and SIM-CARD reader integrated in the radio-phone-navigation system;

- hands free function via the radio speakers;

- microphone located in the front courtesy light;

- external aerial.

The integated radio-telephone-navigation system is a node in the CAN network, via which it exchanges information with the Body Computer and the other electronic control units.

The controls are shown on the integrated radio-telephone-navigation system display.

Some versions are equipped with a series of buttons on the steering wheel: these are used to send out radio and also phone commands.

Other control buttons are located in the front courtesy light.

The stylus aerial is fitted at the rear of the roof: this aerial has three functions (radio/ GSM/ GPS); as far as the telephone is concerned it is a GSM dual band reception aerial (GSM-ETACS at 900Hz and D.C.S. at 1800 Hz).
