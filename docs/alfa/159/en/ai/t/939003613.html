Applies to: all engines; all production periods

With the ignition ON, when the lever on the right of the steering wheel is operated, the windscreen wash/wipe does not work properly

Applies to: all engines; all production periods

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that neither the windscreen wipers nor the windscreen washer is working

Move on to Step 1

1. Only the windscreen wipers are not working

1. Proceed as instructed in the fault diagnosis.

See table J002 WINDSCREEN WIPERS NOT WORKING

2. The windscreen washer is not working

2. Proceed as instructed in the fault diagnosis.

See table J003 SCREEN WASHER NOT WORKING

1

WINDSCREEN WIPER ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Windscreen wiper fuse;
  • Starting exclusion relay;
  • Steering column switch unit power supply

See E3020 WINDSCREEN WASH/WIPE

Move on to Step 2

1. Component defective

1. Replace defective component (in the case of a fuse, find out what caused it to blow)

2. Connections not correct.

2. Restore the correct connections.

2

STEERING COLUMN SWITCH UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the stalk unit is working properly: in particular, the internal resistances the produce the intermittent operation of the windscreen wiper.

Op. 5550A STALK UNIT

End of diagnosis

Intermittent operation function not working properly.

Replace the steering column switch unit

Op. 5550A12 COMPLETE STALK UNIT - R+R FOR VERSIONS WITH AIR BAG
