Removing

- Check that the load carrying compartment trim is not damaged.

- Place the load carrying compartment lining in position.

- Attach the retaining buttons.

Function

Refitting

Removing

- Check that the load carrying compartment trim is not damaged.

- If removed, position the protection and attach the inner retainers.

- Position the load carrying compartment cover and fasten it using the retaining buttons.
