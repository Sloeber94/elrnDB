With the vehicle moving, noise can be heard coming from one of the front doors

Applies to: all engines; all production periods

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems encountered

Operation

First of all check that the moving window is correctly shut.

Check that the wind noise is actually coming from one of the front doors.

Move on to Step 1

Proceed as instructed in the

See table T002 WIND NOISE FROM THE REAR DOORS

Continue following the instructions in the table

See table T010 PASSENGER COMPARTMENT WIND NOISE, LOWER AREA (UNDERBODY)

The wind noise is coming from the sun roof.

Continue following the instructions in the table

See table T020 WIND NOISE FROM THE SUN ROOF

Continue following the instructions in the table

CHECK ON LOCATION OF WIND NOISE FROM FRONT DOORS

Problems encountered

Operation

Carry out the test to locate the wind noise from the front doors accurately

See Test 7005OA FRONT DOOR NOISE LOCALISATION

locate the area where the wind noise is coming from.

End of diagnosis

Check for sealant between the wing and the pillar under the wheel arch liner

Adjust the door hinges
