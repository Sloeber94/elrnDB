The diagnostic equipment signals: Error P0340 (Timing sensor), with detail "signal plausibility"

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

This error is detected if the engine is running and the control unit cannot synchronize the camshaft signal.

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods
