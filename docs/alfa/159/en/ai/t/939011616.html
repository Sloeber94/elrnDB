Applies to: all engines; all production periods

DESCRIPTION

The boot opening geared motor is operated by:

- the special button in the courtesy light;

- the remote control (TEG).

Operation through the remote control takes place in two ways.

- indepedently of the doors: there is a special button on the remote control that allows the boot only to be "unlocked": the boot is released and lifts up slightly. The operation is signalled by the direction indicators flashing twice; when it is closed again the boot returns to the state prior to opening.

- together and at the same time as the unlocking of the doors: the tailgate is considered as a fifth door to all intents and purposes: for the control logic.

See E3040 CENTRAL LOCKING

One of the two modes described above can be selected using a special setup in the instrument panel.

The boot opening function via the button in the courtesy light is disabled (the boot does not open) if the speed of the vehicle is above 10 km/h.

The fuel flap is managed directly by the driver's door node and is therefore connected to the locked/unlocked status of the driver's door.

The boot opening circuit is protected by a specific fuse, located in the junction unit under the dashboard.
