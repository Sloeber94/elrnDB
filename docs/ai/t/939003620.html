J030 WHEN IT RAINS, THE WINDSCREEN IS NOT CLEANED AUTOMATICALLY

Applies to: all engines; all production periods

For vehicles equipped with a rain sensor only, with the ignition on, when the steering column switch unit lever is placed in the automatic position, the windscreen wipers do not work when there is water on the windscreen.

Applies to: all engines; all production periods

1

CHECK THE WIRING

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check connections between:

  • battery;
  • junction unit;
  • steering column switch unit;
  • windscreen wiper control unit;
  • rain sensor;
  • windscreen wiper motor

See E3020 WINDSCREEN WASH/WIPE

Move on to Step 2

1. Wiring broken.

1. Repair the wiring

See E3020 WINDSCREEN WASH/WIPE

2. Fuse burnt out.

2. Replace the fuse and find out what could have caused it to blow.

3. Earth not sufficient.

3. Restore the correct earth.

2

RAIN SENSOR CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the rain sensor is working properly.

Move on to Step 3

The windscreen wipers still carry out a cycle as if set to intermittent operation.

Replace the rain sensor

Op. 5050B70 RAIN/DUSK SENSOR - R.R.

3

WINDSCREEN WIPER MOTOR CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the windscreen wiper motor is working properly

See E3020 WINDSCREEN WASH/WIPE

Move on to Step 4

Windscreen wiper motor not working.

Replace the windscreen wiper motor

Op. 5050B42 WINDSCREEN WIPER MOTOR - R+R

4

WINDSCREEN WIPER CONTROL UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the windscreen wiper control unit is working properly.

End of diagnosis

Windscreen wiper control unit not working.

Replace the windscreen wiper control unit

Op. 5050B06 FRONT AND REAR WASHER CONTROL ELECTRONIC CONTROL UNIT - R R
