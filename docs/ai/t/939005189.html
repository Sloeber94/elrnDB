The diagnostic equipment signals: Error P2002 (particle filter).

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

This error is detected if too many interrupted consecutive regenerations of the diesel particle filter are detected.

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

0

Preliminary checks

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Select the following system on the diagnostic equipment: EDC16C39 Diesel electronic injection system. Delete the errors memorized. Carry out the regeneration of the particle filter, checking that the outcome is positive

Op. 0520G12 PARTICULATE FILTER (D.P.F.) - REGENERATION EXAMINER

Move on to Step 1

The regeneration fails

Continue as described by the diagnostic equipment

1

Exhaust system check

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the seal of the exhaust system is correct, with particular reference to:

  • Catalytic converter
  • Particle filter
  • Temperature sensors
  • Differential pressure sensor

Move on to Step 2

There are leaks or the seal is not perfect

Restore the correct seal. Replace the faulty components, if necessary

2

Check on the operation of the differential pressure sensor

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check correct operation of the differential pressure sensor

See Test 1080BF CHECK DIFFERENTIAL PRESSURE SENSOR OPERATION

End of diagnosis
