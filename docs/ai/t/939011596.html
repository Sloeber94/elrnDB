Applies to: all engines; all production periods; only with equipment: High setup

DESCRIPTION

The door mirrors can be electrically adjusted in two directions using a joystick control located in the door controls on the driver's side: a selection cursor makes it possible to choose either the left or the right mirror. The button controls two electrical motors located in each of the two mirrors: one motor allows the rotation of the mirror on the horizontal axis, another on the vertical axis.

Another button controls the folding back of the mirrors if required (for example when trying to get through a narrow space).

On the HIGH version, in addition to moving the door mirrors manually, it is possible to memorize and later on recall 3 positions defined in relation to the position of the driver's seat; the passenger side rear view mirror is also positioned automatically when reverse gear is engaged.

This entire complex logic is managed by the driver's seat control unit which converses with the Body Computer via the CAN

See E3076 ELECTRICALLY-ADJUSTABLE SEATS

The interior rear view mirror is electrochrome type: i.e. it contains an electronic device which controls the automatic anti-glare function. The automatic antiglare function is disabled when reverse is engaged.

The circuit is protected by a fuse in the junction unit under the dashboard and is operated by the door control units in accordance with the control logic transmitted by the Body Computer via the CAN.

The interior rear view mirror power supply circuit is protected by a fuse in the under-dashboard control unit.
