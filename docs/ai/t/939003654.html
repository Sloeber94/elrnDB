K064 AIR BAG FAILURE WARNING LIGHT ON

Path

Applies to: all engines; all production periods

The brake fluid warning light remains on with the handbrake released.

Applies to: all engines; all production periods

N.B.: The (negative) brake fluid level signal is sent by the sensor to the Body Computer Node which makes it available via the B-CAN to the Instrument Panel Node.

Applies to: all engines; all production periods

The Instrument Panel Node lights up the dedicated warning light and displays the insufficient brake fluid level message; if the warning light is faulty, the appropriate message is displayed.

Applies to: all engines; all production periods
