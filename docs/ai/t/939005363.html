Applies to: engines: 1.8, 1.9 JTS, 2.2 JTS, 3.2 JTS; all production periods

CHECK TO BE PERFORMED

RESOLUTION IF THE CHECK IS NOT OK

1

Select the following parameters on the diagnostic equipment:

- voltage of Lambda sensor upstream of the catalytic converter

- voltage of Lambda sensor upstream of the catalytic converter 2

- Lambda control factor

- Lambda 2 control factor

2

With the engine started, press the accelerator pedal several times, more or less rapidly, and check that the values of the parameters selected vary as a result at a corresponding speed.

The test can be considered over

Move on to Step 3

3

If there is no variation in one or both the Lambda sensors when the accelerator pedal is pressed, check that there are no errors linked to the Lambda sensors in the control unit

Continue as described by the diagnostic equipment

4

If there is a slow response by one or both of the Lambda sensors to the accelerator pedal being pressed, remove the faulty sensors and check that there are no signs of fouling.

The test can be considered over

Move on to Step 5

5

Clean the faulty sensor again with a dry cloth.

Do not use petrol, water or special products to clean the sensor because they could damage it.

If the sensor was fouled by fuel, move on to Step

If the sensor was fouled by oil, move on to Step 8

6

Check that the errors memory does not indicate that there was misfire previously

Continue as described by the diagnostic equipment

7

Check that there are no fuel leaks from the injectors, by carrying out the

See Test 1056BA INJECTOR OPERATION CHECK

The test can be considered over

8

Check that there are no engine oil leaks, as instructed in the

See table X12 ENGINE OIL LEAKS
