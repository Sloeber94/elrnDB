The diagnostic equipment signals: Error U1706 (CAN (NCM – NFR)).

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

This error is detected if the control module detects a fault in the ABS.

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods
