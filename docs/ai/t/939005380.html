Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

When the opening of the boot is requested using the remote control or mechanical key, the alarm system does not switch off

Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

In operational mode, the system, on receiving the boot lid opening command, disables the volumetric/anti-tilt external modules and the perimeter protection from the boot switch inlet.

Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Connect the diagnostic equipment to the body computer node and check, the parameters ambient, that the boot lid status (open or closed) is correctly received.

Move on to Step 4

The status of the boot lid is not received.

Move on to Step 2

2

ELECTRICAL CIRCUIT CHECK

All OK

Problems encountered

Operation

Check that the electrical connection between the boot lid switch and the body computer node is not broken or insulated.

Move on to Step 3

Electrical connection broken or not insulated.

Proceed with restoring the continuity/insulation of the electrical connection between the boot lid switch and the body computer node

See E7015 ALARM

3
