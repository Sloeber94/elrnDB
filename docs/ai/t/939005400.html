N049 THE BLUETOOTH CANNOT BE ENABLED

Applies to: all engines; all production periods

A telephone with a Bluetooth® system cannot be recognized by the vehicle system even if other telephones have been recognized previously.

This table does not consider faults due to service provider or phone function malfunction

Applies to: all engines; all production periods

The following telephones are enabled to operate with the Bluetooth system and are supported by the system on the vehicle:- Audiovox®: SMT 5600 (Orange™ C500)*- Motorola®: V525*, V600*, Mpx220**- Nokia®: 6230, 6600†, 6820, 7610*- Sony Ericsson®: k700i, T610**, T637**, Z600*** The system is not currently able to support a GPRS connection (General Packet Radio Services) when it is connected to this mobile phone.** The system is not currently able to support a hands-free system when it is connected to this mobile phone.† The system is not currently able to support call waiting when it is connected to this mobile phone.

Applies to: all engines; all production periods

Test results

1

BLUETOOTH® OPERATION CHECK

All OK

Problems encountered

Operation

Check whether the telephone is cable of connecting via Bluetooth® to other systems such as other mobile phones, earphone systems or computers

Move on to Step 2

The telephone is not capable of dialogue even with other Bluetooth® systems

The problem is inherent to the phone: the customer must contact a mobile phone service centre

2

REGISTERED TELEPHONES CHECK

All OK

Problems encountered

Operation

Check, in the User Data menu, that not more than four telephones are registered and that the telephone in question is one of these

Move on to Step 4

1. Not more than four telephones are registered but the telephone in question is not one of these

2. Five telephones are registered and the telephone in question is not included

1. Register the telephone

2. Move on to Step 3

3

DELETING REGISTERED TELEPHONES

All OK

Problems encountered

Operation

Following the instructions in the Owner's Handbook, delete all the telephones registered in the system, then start the registration process again, checking that the outcome is positive

End of diagnosis

The fault persists

Move on to Step 5

4

TELEPHONE REGISTRATION

All OK

Problems encountered

Operation

Following the instructions in the Owner's Handbook, register the telephone in question, checking that it is successful

During the registration procedure, an enablement code, shown in the instrument panel, will need to be entered in the telephone

End of diagnosis

The fault persists

Move on to Step 5

5

BLUETOOTH® CHECK

All OK

Problems encountered

Operation

Carry out the Bluetooth network disconnection active diagnosis on the Bluetooth® system and check whether the fault disappears

End of diagnosis

The fault persists

If there is an update CD for the Bluetooth® system, carry out Test 5570TP, otherwise replace the Bluetooth® control unit
