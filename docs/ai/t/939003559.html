Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

With the alarm on the alarm cycles are set off without any apparent cause and without any attempts to break into the vehicle.

Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

If it is not possible to stop the siren and deactivate the alarm using the remote control, simply activate the instrument panel by inserting the key in the key recognition device. The system can recognize the transponder and switch off the alarm system in this way.

Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

PRELIMINARY CHECKS

All OK

Problems encountered

Operation

Check that there is not actually any instrusion in the passenger compartment like an insect that could set off the alarm by moving around or any moving object that could be detected by the ultrasound sensors. Check that the windows are properly shut, especially if there are strong winds.

Move on to Step 1

Insect in the passenger compartment that is detected by the ultrasound sensors when it moves around

Remove the cause of the alarm

Vehicle windows open when there are strong winds

Close the windows
