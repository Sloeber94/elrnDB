K047 MINIMUM ENGINE OIL PRESSURE WARNING LIGHT ON CONSTANTLY

Applies to: all engines; all production periods

The Engine Management node sends a message via the C-CAN network to the Body Computer, which makes it available to the Instrument Panel Node via the B-CAN network.

Applies to: all engines; all production periods

Any faults in the C-CAN network turn on the warning lights of the control units that communicate on this network. The CAN Network Information check is intended to detect this situation.

Applies to: all engines; all production periods

1

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect an Examiner and check on CAN Network Information for the absence of:

  • Inactive node/s
  • Node/s with error/s
  • Node/s with CAN network fault

Move on to Step 6

1. Engine Control Node inactive and/or with error

1. Continue as instructed by the diagnostic equipment

2. Fault in CAN network

2. Continue as instructed by the diagnostic equipment

2

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Use an Examiner to check the possibility of connection to the Body Computer Node, the lack of errors and the presenc of parameters

Move on to Step 3

Presence of errors

Continue as instructed by the diagnostic equipment

3

ACTIVE DIAGNOSIS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the Examiner in Instrument Panel Node mode, check that the minimum oil pressure warning light is correctly activated in Active Diagnosis.

Move on to Step 4

1. The warning light does not flash

1. Replace the instrument panel

Op. 5560B10 CONTROL PANEL - R+R

2. The warning light flashes

2.Continue to step 4

4

OIL PRESSURE SENSOR CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check correct operation of the oil pressure sensor

Move on to Step 5

1. Pressure sensor defective

1. Replace pressure sensor

Op. 1084A40 ENGINE OIL LEVEL SENSOR - R + R

2. Oil circuit pressure incorrect

2.Restore the correct pressure

3. Sensor wiring defective

3.Renew the wiring

5

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Using the Examiner diagnostic equipment check, in Engine Control Node mode, that there are no errors and that the parameters are present.

Move on to Step 6

Fault persists

Replace the Engine Management Control Unit

fault persists
