Pollutant emissions enter the vehicle during automatic operation (failed automatic operation of the recirculation flaps)

Applies to: all engines; all production periods

Only for vehicles equipped with AQS.

Applies to: all engines; all production periods

1

RECIRCULATION MOTOR ELECTRICAL CIRCUIT CHECK

All OK

Problems encountered

Operation

Check the operation of:

- air recirculation motor;

- connection between air motor and climate control system control unit:

See E6020 AIR CONDITIONING

- control on climate control system control unit.

Move on to Step 2

Recirculation motor defective

Replace the recirculation motor

Op. 5040D75 AIR CONDITIONING RECIRCULATION FLAP CONTROL MOTOR - R.R

Connections between recirculation motor and control unit not correct.

Restore the correct connection

See E6020 AIR CONDITIONING

Control on control unit defective.

Replace the climate control system control unit

Op. 5040D18 AIR CONDITIONING CONTROL UNIT - R.R.

2

POLLUTION SENSOR CHECK

All OK

Problems encountered

Operation

Check that the pollution sensor is correctly supplied and working properly by carrying out the

See Test 5040DD Check operation of pollution sensor (AQS)

End of diagnosis

AQS sensor not correctly supplied

Restore the correct power supply

See E6020 AIR CONDITIONING

AQS sensor not working properly.

Replace the AQS sensor

Op. 5010D72 AIR QUALITY SENSOR - R.R. FOLLOWING ELECTRICAL CIRCUIT CHECK
