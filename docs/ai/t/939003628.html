Applies to: all engines; all production periods

With the key on, the trip meter does not zero when the "Km" button in the control panel is operated.

Applies to: all engines; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment to the diagnostic socket.

Check that there are no faults in the instrument panel

Move on to Step 2

Presence of errors

Continue following the instructions for the diagnostic equipment

2

ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check connections between control panel and instrument panel

See E4010 INSTRUMENT PANEL

Move on to Step 3

Connections defective, earth or power supply defective

Restore the correct connections, if necessary, replace the wiring.

3

CONTROL PANEL CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the KM button in the control panel is working properly

Move on to Step 4

Button defective

Replace the control panel

Op. 5560B56 PANEL WITH MULTIFUNCTION DISPLAY AND HEADLAMP ALIGNMENT SWITCHES BUTTONS R R

4

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

End of diagnosis
