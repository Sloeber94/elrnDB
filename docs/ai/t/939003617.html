J020 REARSCREEN AND DOOR MIRROR DEFROSTING NOT WORKING

Applies to: all engines; all production periods

With the ignition ON, when the button in the control panel for the climate control is pressed, the heated rear windscreen and the rear view mirrors do not heat up properly

Applies to: all engines; all production periods

If the battery voltage is below 11.6 V, the heated rear windscreen and rear view mirrors are not supplied by the control unit.

Applies to: all engines; all production periods

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that neither the defrosting of the rearscreen or the rear view mirrors is working.

Move on to Step 1

1. Only the rearscreen is not working.

1. Proceed as instructed in the,

See table J021 HEATED REAR WINDSCREEN NOT WORKING

2. Just the rear view mirrors are not working.

2. Proceed as instructed in the,

See table J022 DOOR MIRROR DEFROSTING NOT WORKING

1

DEFROSTING FUNCTION ON LED CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

When the button in the climate control system panel is pressed, check whether the LED in the actual button comes on to signal that the function is working.

Move on to Step 2

Defrosting LED fails to come on.

Restore the connection between the climate control system control unit and services control unit

See E3020 WINDSCREEN WASH/WIPE

Move on to Step 3

2

DEFROSTING ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Heated rear windscreen fuse;
  • Heated rear windscreen relay;
  • Connection between heated rear windscreen relay and services control unit;
  • Services control unit power supply

See E3030 HEATED REAR WINDSCREEN AND DOOR MIRROR DEFROSTING

Move on to Step 3

1. Connections not correct.

1. Restore the correct connections.

2. Component defective.

2. Replace the component involved (in the case of a fuse, find out what caused it to blow).

3

SERVICES CONTROL UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the services control unit is working properly: in particular, the control function for the rear windscreen and rear view mirrors defrosting

Op. 5505 INSTRUMENT/GAUGE ELECTRICAL CIRCUITS

End of diagnosis

Services control unit not working.

Replace the services control unit

Op. 5505A18 MULTI-FUNCTION CONTROL UNIT - R R
