7005E38 FRONT SIDE DOOR INTERIOR HANDLE- R.R.

Applies to: all engines; all production periods

Removing

Refitting

1. Remove the trim.

2. Undo the bolts.

3. Lift up the grab handle (3a) slightly releasing the retainers (3b).

4. Disconnect the electrical connection for the switches.

Description

Component

ELECTRIC WINDOW CONTROLS ON DRIVER'S FRONT DOOR

See H044 ELECTRIC WINDOW CONTROLS ON FRONT DRIVER'S DOOR

ELECTRIC WINDOW SWITCH ON PASSENGER FRONT DOOR

See H050 ELECTRIC WINDOW SWITCH ON FRONT PASSENGER'S DOOR

5. Keep the interior grab handle complete with switches.

Applies to: all engines; all production periods

Refitting

Removing

- Check that the interior grab handle and the switches are not damaged.

- Connect the electrical connection for the switches.

- Place the grab handle in position and attach the retainers.

- Tighten the bolts.

- Check that the switches are working properly.
