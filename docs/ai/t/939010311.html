Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

The key remote control is supplied by a CR2032 lithium battery (3 V, 220 mAh), remote control operation is ensured between 2.6 and 3.6 V with a maximum current of 15 mA. At least 9000 activations of 1 s duration and 3000 activations of 5 s duration are guaranteed over a period of two years.The battery voltage is monitored to check the charge level: the threshold is set at 2.6±0.06 V. If the remote control receiver detects that the battery is flat, it is still possible to carry out a total of 100 operations.Operating frequency: 433.92 MHz.

CHECK TO BE PERFORMED

RESOLUTION IF THE CHECK IS NOT OK

1

Take out the key battery and connect the diagnostic instrument in Voltmeter mode to the key terminals with the correct polarity.

Check that the voltage exceeds 2.2 Volts.

Replace the battery

Note that after replacing the battery, the remote control variable code must be re-synchronised: this operation is carried out by pressing the remote control key twice.

Note that if the remote control has been activated more than 255 times, variable code synchrony between the sending unit and the receiver will be lost (the receiver will no longer be able to identify a variable code message correctly). Synchrony should therefore be restored by pressing the remote control unit key twice.
