Applies to: all engines; all production periods

The exterior mirrors do not move when the control is operated.

Applies to: all engines; all production periods

The left mirror is adjusted by the Driver's Door Node using information from the joystick on the door handle, the right mirror is aadjusted by the Passenger Door Node using information from the joystick on the driver's door hand. The information from the joystick is sent from the Driver's Door Node to the Passenger Door Node.

Applies to: all engines; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment to the diagnostic connect and check the following at the Driver's Door Node:

In errors ambient

  • that there are no faults

In parameters ambient

  • the plausibility of the parameters for joystick (left/right/up/down).

Move on to Step 3

1. Presence of faults

1. Continue following the instructions for the diagnostic equipment.

2. Mirror selector joystick parameters (left/right/up/down) not plausible.

2. Move on to Step 2.

2

MIRROR ADJUSTMENT JOYSTICK OPERATION CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Remove the control panel following the,

Op. 7005R40 REAR VIEW MIRROR-S AND DOOR MIRROR-S POSITIONING SWITCH UNIT - R.R.

on the driver's door side disconnect the connector and check the operation of the joystick following the

Op. 7005RA CHECK ON OPERATION OF DOOR MIRROS ADJUSTMENT/FOLDING

Move on to Step 3

Mirror control joystick faulty

Replace the external mirrors control joystick

Op. 7005R40 REAR VIEW MIRROR-S AND DOOR MIRROR-S POSITIONING SWITCH UNIT - R.R.
