When the handbrake is released, the rear wheels remain locked

Applies to: all engines; all production periods

1

CONTROL CABLES TRAVEL CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the control cables return travel is free from impediments

Move on to Step 2

Control cables do not slide freely.

Restore correct operation. If damaged, replace the cables involved

Op. 3380A30 HANDBRAKE CABLE - R+R

2

OPERATING LEVER BUTTON CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the operating lever release button returns freely

Move on to Step 3

Adjustment incorrect.

Remove and release the button; if necessary, replace the operating lever

Op. 3380A10 HANDBRAKE LEVER - R+R

3

CHECK ON FASTENING OF CABLE TO REAR BRAKE

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the cable is correctly fastened to the rear brake caliper.

Move on to Step 4

Cable not correctly fastened.

Fasten the cable correctly to the brake caliper.

4

CLEARANCE RECOVERY DEVICE CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the handbrake clearance recovery device is working efficiently.

Move on to Step 5

Rear brake caliper faulty.

Replace the rear brake caliper involved

Op. 3310B36 REAR BRAKE CALIPER (ONE), LEFT OR RIGHT - R.R

5

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present.

End of diagnosis

Fault persists.

Search for the fault starting from another symptom.
