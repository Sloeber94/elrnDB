Removing

Refitting

Op. 5050B10 FRONT WINDSCREEN WASHER JETS - R+R CLEAN AND/OR POSITION

1. Release the seal from the bonnet.

2. Disconnect the pipe (2a) from the connector (2b).

3. Fit a sensor to the end (3a) of the pipe (3b), then extract the actual pipe leaving the sensor in its place (to be used for reinserting the pipe when refitting).

Applies to: all engines; all production periods

Refitting

Removing

- Check that the pipe is not damaged.

- Refit the pipe in place with the help of the sensor.

- Connect the pipe to the connector.

- Attach the seal to the bonnet.

Op. 5050B10 FRONT WINDSCREEN WASHER JETS - R+R CLEAN AND/OR POSITION

- Check that the windscreen washer jets are working.
