Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

When the alarm is switched on using the remote control, the system is activated correctly (acoustic/visual signalling and deterrent LED working), but the central locking system is not working.

Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

The Body Computer Node, having received the alarm on/off command, sends the door closing/opening signal, via the B-CAN, to the driver's door node (which controls the driver's front door lock and the fuel flap lock) and to the passenger door node (which controls the front passenger door lock). The body computer node controls the closing/opening of the boot lid directly (depending on the settings for the operation of the boot lid).

Applies to: engines: 1.9 JTS, 2.2 JTS, 3.2 JTS, 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods
