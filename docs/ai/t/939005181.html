The diagnostic equipment signals: Error P0685 (main relay), with detail "actuator slipping"

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

This error is detected if the main relay switches off too late or does not switch off at all. If the main relay is not switched off after the control units have been inactive for a while, a counter is activated in the engine management control unit. If the main relay is not switched off after an internally programmed period, the fault code is issued.

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods
