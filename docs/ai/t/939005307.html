Op. 7055B54 UNDER ENGINE PROTECTION/GUARD - R.R.

If this procedure is carried out after removing-refitting the propeller shaft, make sure that the "alignment shims" which may have been removed during the removal have been refitted.

Applies to: engines: 3.2 JTS; all production periods

CHECK ALIGNMENT BETWEEN THE PTU AND THE FRONT SECTION "A"

1. Fit the tool prepared previously with the following components as illustrated: the "base" (1a) marked with the letters "A/D"; the "collar" (1b) marked with the letter "A" and the "calibrated pin" (1c) marked with the letter "A".

The spacers available from the Parts Dept. are 2 and 5 mm and should never be used in pairs.

After fitting the spacers refit the brackets using the special bolts depending on the shim used. For 2 mm shims (no. 50505232) use M8 x 1.25 x 32 bolts (no. 50505230); for 5 mm shims (no. 50505234) use M8 x 1.25 x 40 bolts (no. 50505231).

After fitting the spacers, check the propeller shaft angles once again.
