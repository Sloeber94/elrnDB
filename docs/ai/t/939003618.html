J021 HEATED REAR WINDSCREEN NOT WORKING

Applies to: all engines; all production periods

With the ignition ON, when the button in the control panel for the climate control is pressed, the heated rear windscreen does not heat up properly

Applies to: all engines; all production periods

If the battery voltage is below 11.6 V, the heated rear windscreen and rear view mirrors are not supplied by the control unit

Applies to: all engines; all production periods

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the rear view mirrors heat up properly when the button in the climate control system control panel is pressed

Move on to Step 1

The rear view mirrors do not heat up properly

Proceed as instructed in the,

See table J022 DOOR MIRROR DEFROSTING NOT WORKING

1

HEATED REAR WINDSCREEN POWER SUPPLY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Connection to earth of the heated rear windscreen;
  • Heated rear windscreen power supply line

See E3020 WINDSCREEN WASH/WIPE

Move on to Step 2

Connection broken.

Restore the correct connections

2

HEATED REAR WINDSCREEN FILAMENTS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the condition of the heated rear windscreen filaments.

End of diagnosis

Filaments broken.

Restore the condition of the heated rear windscreen filaments. Replace the rear windscreen if necessary
