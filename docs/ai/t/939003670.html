1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment and check, in Instrument Panel Node mode, that there are no errors and that the parameters are present.

Move on to Step 6

1. Impossible to connect to the NQS

1. Move on to Step 2

2. Presence of errors

2. Move on to Step 5

2

ELECTRICAL POWER SUPPLY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the electricity supply to the Instrument Panel Node is correct

See E4010 INSTRUMENT PANEL

Move on to Step 3

Fault in positive electrical supply and/or earth

Renew and/or replace the defective component (in the case of a fuse, find out what caused it to blow)

3

CHECK ELECTRICAL CONNECTIONS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the Instrument Panel Node electrical wiring/connections, in particular that each pin is correctly connected and inserted in its seat

Move on to Step 4

Electrical wiring and/or connections not working

Restore the damaged electrical wiring and/or connections

4

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Use an Examiner to check the possibility of connection to the Instrument Panel Node

Move on to Step 2

Impossible to connect with the control unit

Replace the instrument panel

Op. 5560B10 CONTROL PANEL - R+R

5

ERRORS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check for the presence of one or more of the following errors using the Examiner in Instrument Panel Node mode:

  • CAN line
  • EEPROM memory

Move on to Step 6

1. Detected "no additional information" and/or "BUS off"

1. Continue as described by the diagnostic equipment

2. Fault in EEPROM memory

2. Replace the instrument panel

Op. 5560B10 CONTROL PANEL - R+R

6

ACTIVE DIAGNOSIS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Use the Examiner to check the Autotest function is correctly activated in Active Diagnosis mode

Move on to Step 7

The function in question is not controlled by Active Diagnosis

Replace the instrument panel

Op. 5560B10 CONTROL PANEL - R+R

7

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

End of diagnosis
