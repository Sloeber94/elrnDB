The engagement of the gears is not precise. There is excessive clearance when selecting the gears and the return of the lever to neutral is faulty

Applies to: all engines; all production periods

1

GEAR SELECTION CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the condition of the gear selector ball springs (see Overhauling Gearboxes,

Assembly 2110B

)

Op. 2110B MANUAL GEARBOX WITH DIFFERENTIAL GEARS AND SYNCHRONISERS

Move on to Step 2

Springs or balls damaged

Replace the affected parts

2

GEARBOX CONTROL CABLES CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the gearbox control cables: the ball joints and the bushes should not be worn

Move on to Step 3

Ball joints worn

Replace the gearbox control cables (see

Assembly 2125C

)

Op. 2125C MANUAL GEARBOX EXTERNAL CONTROL (CABLES)

3

GEAR LEVER BALL CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the gear lever ball joint: it should not be worn

End of diagnosis

Ball worn

Replace the gear lever

Op. 2125C24 GEAR LEVER KNOB - R + R
