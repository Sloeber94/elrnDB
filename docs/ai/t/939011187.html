Removing

Refitting

1. Remove the trim.

2. Undo the bolts.

3. Remove the inner grab handle.

Applies to: all engines; all production periods; only with equipment: Low setup

Refitting

Removing

- Check that the interior grab handle is not damaged.

- Place the grab handle in position.

- Tighten the bolts.

- Place the trim in position.

Applies to: all engines; all production periods; only with equipment: High setup

Removing

Refitting

1. Remove the trim.

2. Undo the bolts.

3. Lift up the inner grab handle.

4. Disconnect the electrical connection.

Description

Component

LEFT REAR DOOR WINDOW SWITCH

See H053 ELECTRIC WINDOW SWITCH ON LEFT REAR DOOR

RIGHT REAR DOOR WINDOW SWITCH

See H054 ELECTRIC WINDOW SWITCH ON RIGHT REAR DOOR

5. Keep the grab handle and switches.

Applies to: all engines; all production periods; only with equipment: High setup

Refitting

Removing

- Check that the interior grab handle is not damaged.

- Attach the electrical connection.

- Place the grab handle in position.

- Tighten the bolts.

- Place the trim in position.
