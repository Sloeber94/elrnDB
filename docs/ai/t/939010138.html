With the vehicle moving, noise can be heard coming from one of the rear doors.

Applies to: all engines; all production periods

0

PRELIMINARY CHECKS

All OK

Problems encountered

Operation

First of all check that the moving window is correctly shut.

Check that the wind noise is actually coming from one of the rear doors.
