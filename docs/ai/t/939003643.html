K038 MILOMETER/TRIP METER FLASHING

Path
Fault diagnosis > K INSTRUMENT PANEL > K038 MILOMETER/TRIP METER FLASHING
Kind
fault diagnosis table (symptom -> numbered test steps)
Applies to

Interactive page
https://sloeber94.github.io/elrnDB/#/939003643

Applies to: all engines; all production periods

At the end of the check, the mileometer/trip counter on the panel begins to flash

Applies to: all engines; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect an Examiner and check that the Instrument Panel Node is aligned in Control Unit Test, Other System Group and Proxy Alignment Procedure modes.

Move on to Step 8

1. Impossible to carry out Proxy alignment

1. Move on to Step 2

2. Alignment not carried out

2. Carry out Proxy alignment

2

CHECK INSTRUMENT PANEL

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the installed panel reflects the vehicle specifications (it is not possible to install the panel of a petrol version on a diesel version)

Move on to Step 3

Panel does not correspond to the vehicle specification

Replace instrument panel

3

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment and check, in Instrument Panel Node mode, that there are no errors and that the parameters are present.

Move on to Step 8

1. Impossible to connect to the NQS

1. Move on to Step 4

2. Presence of errors

2. Move on to Step 7

4

ELECTRICAL POWER SUPPLY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the Instrument Panel Node elecricity supply is correct

See E4010 INSTRUMENT PANEL

Move on to Step 5

Fault in positive electricity supply and/or earth

Renew and/or replace the defective component (in the case of a fuse, find out what caused it to blow).

5

CHECK ELECTRICAL CONNECTIONS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the Instrument Panel Node electrical wiring/connections, in particular that each pin is correctly connected and inserted in its seat

Move on to Step 6

Electrical wiring and/or connections not working

Restore the damaged electrical wiring and/or connections

6

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Use an Examiner to check the possibility of connecting to the Instrument Panel Node

Move on to Step 7

Impossible to connect with the control unit

Replace instrument panel

7

CHECK ERRORS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check for the absence of one or more of the following errors using the Examiner in Instrument Panel Node mode:

  • CAN line
  • EEPROM memory

Move on to Step 8

1. Detected "no additional information" and/or "BUS off"

1. Continue as described by the diagnostic equipment

2. Fault in EEPROM memory

2. Replace instrument panel

8

ACTIVE DIAGNOSIS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Use an Examiner to check that the Autotest function is correctly activated in Active Diagnosis mode

Move on to Step 9

The function under examination is not controlled by Active Diagnosis

Replace instrument panel

9

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present.

End of diagnosis
