The diagnostic equipment signals: Error P0503 (vehicle speed inconsistency).

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

This error is detected if the junction unit does not receive the vehicle speed signal or the fuel consumption is too high compared with the power produced.

Applies to: engines: 1.9 JTD 8V, 1.9 JTD 16V, 2.4 JTD 20V; all production periods

1

Error deletion

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Press the START/STOP button to turn off the engine and then press is again.

In the system: Diesel EDC16C39 electronic injection system, delete the errors.

Move on to Step 2

2

road tests

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Drive the vehicle in different driving conditions (engine speed and engine load) for a long stretch.

Listen out for any unusual noises and other system irregularities.

Read the fault codes and record them together with the status after the road test and check that the following error is no longer present: P0503 - Vehicle speed inconsistency

End of diagnosis
